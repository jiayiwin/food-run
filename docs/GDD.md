## 2. 操作（单手，全在屏幕下半部）

| 操作 | 手势 | 说明 |
|---|---|---|
| 跳 | 上滑 / 轻点（手指按住不动 70ms 就起跳，不等抬手） | 固定跳高 108px、滞空 0.56s；**不做按住变高**（会和下滑打架） |
| 滑铲 | 下滑 | 0.55s；头顶有横杆时自动保持趴着（钻杆）；空中下滑 = 急降，落地接滑铲 |
| 选左 / 选右 | 左滑 / 右滑，或点卡片 | 跳和选可以同时进行（空中也能选） |
| 冲刺 | 右滑（没有卡片时） | 只在**被追时**、或脚下是 ▶▶ 区时（路口闪绿、选了电梯后的电梯门前）生效：0.5 秒 ×1.25、冷却 2.5 秒；其余时候右滑不做事（脚下灰环闪一下）。左滑在跑酷里永远不做事（不做左滑急停） |
| 便利店 | 点商品，或 ◀ ▲ ▶ 滑 | 下滑 = 不买了 |
| 电梯轿厢 | 左右滑 / 点卡片（同事的题）；轻点 / 按住 / 上滑 / 点大圆钮（关门键） | 轿厢里只有这两种操作，跳、滑铲、冲刺都关掉 |

**斜划**：跑酷时水平位移要超过竖直的 1.4 倍才算左右滑，斜着往上划一律算跳、斜着往下划算滑铲（之前「谁大算谁」，偏右 45° 的上划会被判成右滑，这一跳就丢了）。答题卡打开时仍按「谁大算谁」。NPC 快弹题（离弹题不到 0.6 秒路程）和刚选完 0.35 秒内，横划什么都不做。

容错：土狼时间 0.08s、输入缓冲 0.12s、障碍判定框四周缩 3px、读题弹出 0.15s 内不收选项、选完 0.45s 内保证没有障碍到脸上。

**冲刺的规矩**（铁律「新动作没做只丢时间」）：
- 能不能冲画在主角鞋底：被追或在 ▶▶ 区时脚下一个椭圆环，**青色 = 现在右滑就能冲**；灰色（衬一圈深紫，浅色地面上也看得见）= 冷却中（随冷却从 0.65 倍长回原大）或正在读题 / 快弹题（这时右滑归答题）。不放 HUD。鞋底环和右滑共用同一个判断（`dashReady`），环亮着右滑就一定有效：刚进一个没冲过的 ▶▶ 区会清掉冷却，所以被追、冷却中踏进闪绿的 ▶▶ 区时环也是青色。下车跳回人行道的 0.25 秒里，环和速度线跟着画面上的人走。
- 前方 1.05 秒路程内有没过的障碍时冲刺**不加速**，只给甩追兵的距离（一次 +25px）；更远才 ×1.25。所以任何两次操作的间隔都不低于障碍间距表，间距表不用改。读题时也不加速。
- 冲刺中：大步前倾，鞋底甩出 3 条青白速度线（底下描一道深色，公司浅紫地面上也看得见），「呼」一声上扬音。
- 从不冲刺也一定甩得掉（测试：每题选错 + 完美操作 + 从不冲刺，8 个种子零被抓）。
- 埋点（开发版结算页，可复制）：冲刺次数、其中被追时几次、冲刺中或冲完 0.5 秒内撞上几次。首测时这个比例偏高，就把「前方多远不加速」从 1.05 秒调小。滑动埋点在开局卡、到家过场、教学定格时不计；冲刺成功的那一下横划不算「横划完马上撞上」的误划。

## 3. 跑酷

- **速度按距离算**：v(x) = √(240² + 2x)，封顶 420 px/s（约开跑 180 秒时）。不随中途减速漂移，排障碍能算准。
- **镜头随速度拉远**：缩放 1.0 → 0.8，最高速时仍能提前 0.83 秒看到障碍。
- **迎面移动的障碍**（溜坡单车、滑板车小孩、转椅）出画前在右缘出一块白底红 **!** 预警牌（缩放脉冲，不换色，红色店面前也认得出）；井盖前有「施工中」牌。
- **障碍间距按反应时间排**：跳→跳 ≥0.86s，跳→滑 ≥0.70s，滑→跳 ≥0.62s，滑→滑 ≥0.70s，迎面移动 +0.15s；用该段最高速换算成距离。移动障碍记录「相遇点」，运行时按主角离它多远倒推位置，主角怎么减速都在算好的地方相遇。
- **可解性**：机器人测试保证完美操作零碰撞（8 个种子 × 全程），见 `test/run.test.js`。

| 路段 | 障碍 |
|---|---|
| 公司 | 文件箱、滑行转椅（迎面）、「Q4 冲刺」横幅（只能滑）、小心地滑 |
| 街道 | 水坑（轻：只减速）、锥桶、溜坡单车（迎面）、店招横杆（滑）、台阶（能站）、遛狗绳、脚手架（滑）、没盖的井、**违停车开门**（跳）、**溅水的水坑**（跳，轻） |
| 小区 | 水坑、溜坡单车、台阶、遛狗绳、快递三轮（能站）、晾晒被单（滑）、滑板车小孩（迎面）、垃圾桶 |
| 回家 | 快递纸箱、楼道电动车 |
| 楼梯间（只有走楼梯才跑） | 拖把水桶（跳，亮黄）、文件箱、小心地滑 |

撞障碍：踉跄 1.2 秒（速度 ×0.55 渐回）、饱腹 −2、耽误 0.5 分钟、连击清零。掉井：爬出来 1 秒、耽误 2 分钟。遛狗绳判定高 20（和拆图后的绳子 + 狗对齐）。

**减速的公平**：被缠住（×0.6）、踩水（×0.85）、被追的拖慢期（×0.8）都是立刻生效、结束时**限速回升**（0.6 → 1 用 0.5 秒），不会在你按慢速起跳的那一下突然提速撞上；前方 2 秒路程内有遛狗绳这类宽障碍时，减速不会把速度压到「跳不过」的速度以下（每种跳类障碍最低要多快才跳得过按跳跃弧线算好，都 ≤ 最低速 240）。满技能机器人 400 个种子 × 好 / 坏 / smart 选法 × 冲不冲刺：0 碰撞。

**晚高峰马路**（街道，伪 2.5D 三层：后人行道 → 跑道 → 马路）：
- **车流**：马路上每 1.5–4 秒（世界时间）来一辆车，靠路缘的车道对向开来、靠镜头的车道从后面超过你，同屏最多 3 辆；纯画面，没有碰撞、不出预警。读题时车淡到 0.3，蹭车时你身边 ±300px 不来车，进出街道 300px 渐隐，入夜亮车灯。外卖电动车周围（选择卡、蹭车时围着你，下车后跟着开走的小哥）离它 200px 内的车全透明、200–300px 渐隐，溅水车也一样，车身不会从电动车上开过去。暂停、进店时车也停（按世界时间走）。
- **违停车开门**：违停车停在后人行道上（按背景调色、没有外圈），后门朝跑道甩开，门是障碍（宽 30、高 44、跳；有外圈、右缘有白底红 ! 预警，双闪 2Hz）。按主角位置开门：离车门 1.1×v 开始甩，0.9×v 全开，门出现在画面里时已经开着或正在开。第一次遇到提示「违停车要开门：跳！」。
- **溅水**：排完路后用单独的随机流把街道里 35% 的水坑原地换成「溅水的水坑」（位置、宽度、躲法都不变）。主角离它 0.8×v 时水面开始一闪一闪（街道任何速度下这时水坑都在画面里），靠路缘车道一辆**对向车**（和这条车道的车流同向、同速）开过来，0.55×v 时前轮压到水坑、30px 高的水墙升起，跑过去后淡出。全程按主角位置算，和时间无关（主角停下车也停）。踩上去和水坑一样只减速（×0.85 0.6 秒、断连击），另外记下「被车溅了」（门口妈妈会问「裤子咋湿了？」，普通水坑踩湿了不算）。无敌时（下车、撞完）踩过水坑不算。蹭车经过溅水坑：车淡出、不起水墙、没有水声（人在马路上本来也碰不到）。
- **问「蹭不蹭」时**外卖小哥靠到路缘、停在主角身后，不被答案卡挡住；蹭的话上车那 0.25 秒和主角一起回到马路上。

**斑马线路口**（全程关街道 3 个：10500 / 27000 / 29700；路线版本 3）：
- **灯态**开局按种子定好（单独的随机流，调灯不改路）：绿 35%、红 30%、闪绿 35%，红灯每局最多 2 个，红灯等 1.0–1.5 秒。灯态定义为「主角到停止线那一刻」的灯，离停止线 2.0 秒路程时（这时停止线还不在画面里）**灯牌**出现、灯态生效。
- **绿灯**：什么都不用做。**闪绿**：停止线前 1.0–0.1 秒路程地上出现 ▶▶，区里右滑冲刺就过（+100「抢到绿灯！」，冲刺姿势一直保持到踏上斑马线）；被追时冲过闪绿 = 踏上斑马线那一刻身后变红灯，**追兵被拦下、当场甩掉**。没冲就停下等一轮 1.5 秒：开始刹车后人还在 ▶▶ 区里时，灯牌 / 杆顶灯 / 提示音照样是闪绿、鞋底环青色、右滑照样能过；出了 ▶▶ 区才一起变红（地上 ▶▶ 和「右滑冲过去」提示条同时收掉），灯和这一刻右滑的结果始终对得上（同一个判断 `crossDashOpen`，灯态 `crossLamp` 和规则都在 run.js）。**红灯**：离线 0.35 秒路程开始匀减速，**自动停在白色停止线后**，等完自动起跑（0.5 秒提到全速）。
- **不操作永远安全**：只丢时间（刹车多 0.35 秒 + 等待 + 起步 0.25 秒），不撞、不断连击、不扣饱腹（只按正常速度掉）、不碎饭盒；等灯时能原地跳，不能冲刺。每局最多等 2 次，等满后后面的路口在灯牌出现时直接变绿。
- **追兵也守红灯**：从开始刹车到重新起跑，追兵的距离和计时都冻住（追兵站着干着急），所以被追时遇红灯照样甩得掉。
- **路口窗口**（停止线前 2.0 秒路程到斑马线后 0.5 秒路程）里不放障碍、不摆零钱、不生成车流、只出路口自己的提示（灯牌一出来，路口提示从整个提示队列里挑出来先出，顶掉正在显示的别的规则提示，那条刚出来不到 1 秒就放回队里过完再出；闪绿路口里被追时「右滑冲刺」的提示也能出；路口外不出路口提示、也不记「看过」，留给下一个路口），路段字卡推迟到过完路口；也不和任何读题（含 NPC 预出现）、蹭车重叠。主角停在线后时，后面最近的迎面移动障碍也在画面外，不会冻在半路。

## 4. 限时二选一

**节奏**：NPC 提前约 1.5 秒出现在前方（头顶名字），走到跟前弹题。读题时间 公司 3.0s → 街道 2.6→2.1s → 小区 2.0→1.7s → 家门 1.5s（真实时间）；读题时世界放慢到 0.5 / 0.6 / 0.75 / 1.0。**NPC 朝你走过来的位置本身就是倒计时**：走到脸前 = 时间到。

**文案约束**：台词 ≤14 字，选项 ≤8 字；家门口台词 ≤6 字、选项 ≤4 字（测试强制）。

**判定顺序固定**：资源 > 记仇 > 疲劳 > 基础。

1. **资源**：花钱的选项钱不够 → 必坏（「你钱包比我脸还干净」）；饱腹 <25 时说真话一律放行（「看你饿的，快回去吃饭」）。
2. **记仇**：对记仇的人重复上次那类借口 → 必坏（「又来这套？」）。
3. **疲劳**：工作 / 身体 / 家里 / 没钱 / 装傻 这 5 类「借口」，同一类本局第 3 次用必坏（「这借口我今天听三遍了」）。
4. **基础**：每个选项写好的好 / 中 / 坏。约 30% 的题反直觉（对 Tony 说「我没钱」反而被分期，「我秃了」才放行）。

**卡面信息足够推理**：气泡上有 NPC 的两个性格标签（老刘「较真·爱面子」）；卡片左上角是借口类型 +「已用×N」（第 2 次标红）、价格（买不起标红）、「上次说过」。

**结果**：好 → +100（1 秒内选完再 +50），NPC 愣在原地被甩下；中 → 放行但有代价（减速 / 扣饱腹）；坏 → 被追。超时：70% 当坏处理，30%「他接了个电话走了」。左右顺序随机，背不出「右边总是好的」。

**记仇回访**：选坏的人 25–45 秒后在后面路段再出现（每局最多 2 次），台词引用你上次的原话：「你不是说『我去趟厕所』吗？」。一个选项是死不改口（必坏），另一个是专属反击；选对 = **和解**：+300，并补回 1 个饭盒（每局一次）。

**连锁**：拿了莉莉的蛋糕（+15 饱腹），但那是老刘的 → 老刘来要说法；跟 Amy 说「那天我结婚」→ 阿杰追来八卦；借充电宝给阿杰 → 之后「手机没电」成了真话；挂老刘电话 → 他会记仇。

## 5. 追逐

选坏后 NPC 从左后方追来：初始距离 80px，前 2.5 秒被搭话拖慢（×0.8，每秒被拉近 28），之后 4 秒甩开期（每秒拉开 8）。

| 事件 | 距离变化 |
|---|---|
| 干净躲过一个障碍 | +18（惊险再 +10） |
| 撞障碍 / 掉井 | −50 |
| 蹭外卖车 | 每秒 +80 |
| 能量饮料 | 下次被追先跑 60 |
| 冲刺 | 一次 +25（0.5 秒里匀速加上） |

距离 ≥140 或甩开期结束 = 甩掉；<0 = 被逮住：1.4 秒演出，饭盒 −1、耽误 3 分钟、饱腹 −5。**干净地跑一定甩得掉**（测试：每题都选错 + 完美操作，8 个种子零被抓）；撞一次还能救，撞两次基本被逮。

## 9. 新手引导

**选主角**：新玩家第一次进游戏、老存档还没选过时，先到「选一位打工人」：两张大卡片画着男 / 女主角（默认高亮当前那位，没选过是男主角），一定要点「就是 TA 了！」确认；之后在标题页底部「换主角」随时能换（见 13.2；按钮上是当前主角的头像，女主角取景露出马尾；从这个按钮进来时页面有返回键，底下不再提示「之后在首页底部换主角」）。

新玩家从**序章**开始（标题页「下班！」去当前进度的关卡）：老刘第一题世界停住等你选（左右箭头 + 指尖示意）；第一个文件箱前定格教「上滑 / 点一下：跳」；第一条横幅前定格教「下滑：滑铲」。之后的关卡每关只教一样新东西（见第 13 节）。自由下班、今日挑战、好友卡永远进全程关，没做过序章的第一局照旧带上面三步教学（路不变）。之后第一次被追、第一次借口用到第 2 次、第一次遇到记仇、第一次饿到 <25，各弹一次黄色提示条（记在存档里，只出一次）。**每局最多 4 条新提示**：同时排着几条时按「被追 > 冲刺 > 路口 > 违停车 > 家里的事 > … > 借口疲劳 > 记仇 > 饿了」出，没轮到的这局不显示、存档也不记，下一局再出；马上就有定格教学讲同一件事时（周二第一次被追、周三第一个闪绿），提示条不先弹一次。标题页常驻三步图示：躲障碍 · 两秒选回答 · 别被逮 3 次。

**全程关的软版本**（玩家可能一关都没打过就从今日挑战、好友卡进来）：没学过冲刺 → 第一次被追只出提示条「被追时右滑：冲刺！」；没学过电梯（没通关周二）→ 路线卡照常、超时走楼梯，电梯里外卖那一拍不出关门键，小哥直接进来（没有惩罚）；没学过路口 → 第一个路口出「闪绿灯：右滑冲过去！」/「红灯自动停，等一下就好」；违停车首遇提示「违停车要开门：跳！」。软版本只改提示和按钮，不改路线。

## 13. 关卡数据

整局路线写成关卡数据（`js/data/levels.js`）：`full`「自由下班」就是上面那条 62,000px、约 200 秒的路，同种子排出的路、机器人到家时刻、评级、得分和数据化之前完全一样（`test/fixtures/routes.json` 的路线快照和行为快照锁住）；另有「一周通勤」四关（见 13.1）。结构：

- **坐标是世界 x，速度公式全局通用**：短关从 x0 起跑（例如从 6,000 开始，起步就是 264 px/s），速度、移动障碍、间距表、机器人都不用改。
- **路段**可以带 `theme`（画面和读题时间按哪段算，例如楼梯间按公司）、`slowK`（跑速系数，标准时间按同一系数算）、`gate: false`（不画出口门）、`minor`（进度条不画刻度）。
- **选择槽**照旧；来电槽可以写 `caller` 指定来电人（家庭剧本用）；`route`（路线卡，配 `branch`）；`chase`（追逐槽：追兵直接冲出来，见下面）。
- **电梯 / 楼梯分支** `branch: { id, card, door, exit, beats }`：card 路线卡的槽位，door 电梯门（门洞中心），exit 汇合点；`beats: 'seed'` 停层按种子排，或写死 `['npc', 'takeout']`（周二教学用）。楼梯间是 [door, exit] 里的子路段（`slowK 0.75`、`gate: false`、`minor`）。门前 ▶▶ 区到大门后 1 秒路程整段并进不放障碍的区间（`courseBlocks`）；分支校验 `checkBranch`。调试参数 `route=lift|stairs`（机器人选哪条；人玩时是超时默认走哪条）。
- **随机段**可以有多段、各自加稀（`densityK`）或限定障碍种类；**手写障碍**不吃种子、不摆零钱；随机段前后都和手写障碍保持反应间距（落在随机段里面的手写障碍，随机段排到它跟前会把它当成「上一个」，从它后面接着排）。
- **追逐槽** `{ kind: 'chase', npc, line, hold? }`：不出题，追兵从左后方冲出来直接追，头顶喊 `line` 1.6 秒；已经在被追就换人追（不当场被逮：这里没有选项）；`hold: 'door'` 跑到电梯门前都甩不掉（甩开期不计时、距离封顶在甩开线下 1px），过了门照常进甩开期。窗口 `[x − 0.45v, x + 0.8v]` 不放障碍。
- **定格教学** `teach`（每关 ≤3 个，学过的不再定格，不算世界停住）：`choose` 第一题等你选、`jump` / `slide` 手写障碍上的 teach、`dash` 第一次被追 0.5 秒后定格「被追了：右滑冲刺！」、`lift` 电梯里第一拍外卖等你点关门「点一下：关门！」（定格时轿厢不推进、不计时）、`crossdash` 第一个闪绿路口进 ▶▶ 区定格「闪绿灯：右滑冲过去！」。`learn`：通关后写进存档的「学会了」。
- **规则** `rules: { chase: false }`：答错不追，只有反应台词（序章，不会失败）。
- **星级** `stars`：★1 到家；★2 到家时刻取整分钟 ≤ 标准 + `par.star` 且最多碎 1 个饭盒；★3 本关绝活（`test(stats)`）。三颗各自独立，没到家一颗不亮，存档取历史并集；带薪摸鱼这一局 ★3 不亮。`tip3` 是没拿 ★3 时结算页的一句提示。
- **关卡种子**：写死一个，每次同一条路；题目和左右顺序仍随这一局的种子。
- **时钟倍率**：不写就按本关纯跑时长自动缩放（见第 7 节）；`par` 里的余量和各条线都是这一关时钟上的分钟数。
- **路线版本号** `COURSE_VERSION`：同种子排出的路有任何变化就 +1，路线快照同时重写（`node tools/golden.mjs --write`），测试强制两者同步。现在是 6（2 晚高峰马路：违停车开门进街道障碍池、街道 35% 的水坑换成溅水的水坑、蹭车那段不摆包子；3 斑马线路口：路口窗口里不放障碍；4 写字楼电梯：5600 的同事槽换成 6050 的路线卡、门前区 + 楼梯间单独排、大门后 1 秒空地；5 全程关楼梯间缩短到 6920–7700、街道从 7700 开始，路线快照开始锁每个路口的灯态和红灯等几秒：灯不一样也不是同一局；6 家庭剧本：「跳起来够」的拾取点前 0.9 秒、后 1.0 秒路程剔掉障碍，区间外和平常日逐个相同）。全程关的标准时间按两条路里慢的那条算，余量 2.2 分钟：没有红灯的种子 18:49，两个红灯的 18:50，一个红灯的看电梯停几层（400 个种子 187 个 18:49、213 个 18:50，`balance` 写区间和众数）。路口窗口里也不许有手写障碍（`checkCrossings` 查）。
- **车流开关** `traffic`：缺省 true，街道路段画车流；**▶▶ 区** `course.zones`（路口闪绿灯、选了电梯后的电梯门前）：主角在区里时右滑能冲，刚进区那一下冷却清零。
- **路口** `crossings: [{ x, light?, wait? }]`：x 是停止线位置；`light` 写死灯态（周三关会用），不写按种子抽；路口窗口自动并进不放障碍的区间（`courseBlocks`）。调试参数 `xlight=red|green|flash|worst` 覆盖灯态（只改灯，不改路）。
- **家庭剧本接入点**（`js/game/story.js`，纯函数、不碰 `run.rng`，内容见 13.3）：`run.js` / `choice.js` / `play.js` 只通过它问——门口出哪道题（`door`）、家里来电是谁说什么（`pickCaller` / `caller` / `onCall`）、开局一句（`introLine`）、进店卡台词和货架（`storeLine` / `shopItems`）、买东西（`onBuy`）、拾取家里要的东西（`onPickup`）、晚饭档加减（`mealAdjust`，一局只在结算时调一次）、结算里的 family 字段（`summary`）、路线上要空出来的拾取区间（`storySpans`，整条路照常生成后再剔掉，不改随机数消耗）。
