# 《狂奔吧，打工人》策划案（定稿）

> 18:00 下班铃一响，从工位冲回家吃上热饭。横版自动跑酷，缝进 1.5–3 秒的限时二选一：同事、主管、HR、Tony 老师、王阿姨轮番拦你，选错就被追。
> 宣传语：**别犹豫，选了就跑。**

平台：微信小游戏（竖屏，Canvas 2D，单手）。单局约 3.5 分钟。

本文是三份方案（手感 / 内容 / 循环）经两位评审打分后的合并定稿，所有数值都以代码为准：`js/data/tune.js`、`js/data/npcs.js`、`js/data/events.js`、`js/data/obstacles.js`。

---

## 1. 一局怎么玩

| 阶段 | 路段 | 距离（px） | 约时长 | 内容 |
|---|---|---|---|---|
| 1 | 公司 | 0 – 8,000 | 31s | 老刘开局 2 秒就来拦（3 秒冲突钩子），再抽 2 位同事 |
| 2 | 街道 | 8,000 – 32,000 | 77s | Tony、Amy、记仇回访；来电、外卖小哥、便利店 |
| 3 | 小区 | 32,000 – 56,000 | 62s | 王阿姨、保安老周（门禁必出）；来电、便利店；**开始边跳边选** |
| 4 | 回家 | 56,000 – 62,000 | 15s | 楼道冲刺，家门口妈妈终极一问 |

- **赢**：推开家门 → 饭桌演出 → 「下班战报」。
- **输**：被逮住 3 次（3 个饭盒碎完），或饱腹归零。失败页由最后拦住你的人决定「今晚的饭：____」（老刘：会议室的冷盒饭；王阿姨：和她侄女的相亲饭……）。
- **时间不会让你输**，只决定评级和晚饭档次，保证轻度玩家也能看到结局。

## 2. 操作（单手，全在屏幕下半部）

| 操作 | 手势 | 说明 |
|---|---|---|
| 跳 | 上滑 / 轻点（手指按住不动 70ms 就起跳，不等抬手） | 固定跳高 108px、滞空 0.56s；**不做按住变高**（会和下滑打架） |
| 滑铲 | 下滑 | 0.55s；头顶有横杆时自动保持趴着（钻杆）；空中下滑 = 急降，落地接滑铲 |
| 选左 / 选右 | 左滑 / 右滑，或点卡片 | 跳和选可以同时进行（空中也能选） |
| 便利店 | 点商品，或 ◀ ▲ ▶ 滑 | 下滑 = 不买了 |

容错：土狼时间 0.08s、输入缓冲 0.12s、障碍判定框四周缩 3px、读题弹出 0.15s 内不收选项、选完 0.45s 内保证没有障碍到脸上。

## 3. 跑酷

- **速度按距离算**：v(x) = √(240² + 2x)，封顶 420 px/s（约开跑 180 秒时）。不随中途减速漂移，排障碍能算准。
- **镜头随速度拉远**：缩放 1.0 → 0.8，最高速时仍能提前 0.83 秒看到障碍。
- **迎面移动的障碍**（溜坡单车、滑板车小孩、转椅）出画前在右缘闪 **!** 预警；井盖前有「施工中」牌。
- **障碍间距按反应时间排**：跳→跳 ≥0.86s，跳→滑 ≥0.70s，滑→跳 ≥0.62s，滑→滑 ≥0.70s，迎面移动 +0.15s；用该段最高速换算成距离。移动障碍记录「相遇点」，运行时按主角离它多远倒推位置，主角怎么减速都在算好的地方相遇。
- **可解性**：机器人测试保证完美操作零碰撞（8 个种子 × 全程），见 `test/run.test.js`。

| 路段 | 障碍 |
|---|---|
| 公司 | 文件箱、滑行转椅（迎面）、「Q4 冲刺」横幅（只能滑）、小心地滑 |
| 街道 | 水坑（轻：只减速）、锥桶、溜坡单车（迎面）、店招横杆（滑）、台阶（能站）、遛狗绳、脚手架（滑）、没盖的井 |
| 小区 | 水坑、溜坡单车、台阶、遛狗绳、快递三轮（能站）、晾晒被单（滑）、滑板车小孩（迎面）、垃圾桶 |
| 回家 | 快递纸箱、楼道电动车 |

撞障碍：踉跄 1.2 秒（速度 ×0.55 渐回）、饱腹 −2、耽误 0.5 分钟、连击清零。掉井：爬出来 1 秒、耽误 2 分钟。

## 4. 限时二选一

**节奏**：NPC 提前约 1.5 秒出现在前方（头顶名字），走到跟前弹题。读题时间 公司 3.0s → 街道 2.6→2.1s → 小区 2.0→1.7s → 家门 1.5s（真实时间）；读题时世界放慢到 0.5 / 0.6 / 0.75 / 1.0。**NPC 朝你走过来的位置本身就是倒计时**：走到脸前 = 时间到。

**文案约束**：台词 ≤14 字，选项 ≤8 字；家门口台词 ≤6 字、选项 ≤4 字（测试强制）。

**判定顺序固定**：资源 > 记仇 > 疲劳 > 基础。

1. **资源**：花钱的选项钱不够 → 必坏（「你钱包比我脸还干净」）；饱腹 <25 时说真话一律放行（「看你饿的，快回去吃饭」）。
2. **记仇**：对记仇的人重复上次那类借口 → 必坏（「又来这套？」）。
3. **疲劳**：工作 / 身体 / 家里 / 没钱 / 装傻 这 5 类「借口」，同一类本局第 3 次用必坏（「这借口我今天听三遍了」）。
4. **基础**：每个选项写好的好 / 中 / 坏。约 30% 的题反直觉（对 Tony 说「我没钱」反而被分期，「我秃了」才放行）。

**卡面信息足够推理**：气泡上有 NPC 的两个性格标签（老刘「较真·爱面子」）；卡片左上角是借口类型 +「已用×N」（第 2 次标红）、价格（买不起标红）、「上次说过」。

**结果**：好 → +100（1 秒内选完再 +50），NPC 愣在原地被甩下；中 → 放行但有代价（减速 / 扣饱腹）；坏 → 被追。超时：70% 当坏处理，30%「他接了个电话走了」。左右顺序随机，背不出「右边总是好的」。

**记仇回访**：选坏的人 25–45 秒后在后面路段再出现（每局最多 2 次），台词引用你上次的原话：「你不是说『我去趟厕所』吗？」。一个选项是死不改口（必坏），另一个是专属反击；选对 = **和解**：+300，并补回 1 个饭盒（每局一次）。

**连锁**：拿了莉莉的蛋糕（+15 饱腹），但那是老刘的 → 老刘来要说法；跟 Amy 说「那天我结婚」→ 阿杰追来八卦；借充电宝给阿杰 → 之后「手机没电」成了真话；挂老刘电话 → 他会记仇。

## 5. 追逐

选坏后 NPC 从左后方追来：初始距离 80px，前 2.5 秒被搭话拖慢（×0.8，每秒被拉近 28），之后 4 秒甩开期（每秒拉开 8）。

| 事件 | 距离变化 |
|---|---|
| 干净躲过一个障碍 | +18（惊险再 +10） |
| 撞障碍 / 掉井 | −50 |
| 蹭外卖车 | 每秒 +80 |
| 能量饮料 | 下次被追先跑 60 |

距离 ≥140 或甩开期结束 = 甩掉；<0 = 被逮住：1.4 秒演出，饭盒 −1、耽误 3 分钟、饱腹 −5。**干净地跑一定甩得掉**（测试：每题都选错 + 完美操作，8 个种子零被抓）；撞一次还能救，撞两次基本被逮。

## 8. 评级、晚饭、战报

- **评级**：S ≤18:52 且没碎饭盒；A ≤19:00 且碎 ≤1；B ≤19:12；其余 C。
- **晚饭**：按到家时间 红烧肉 / 番茄炒蛋 / 剩菜热一热 / 泡面，妈妈的电话和终极一问 ±1 档；点了外卖且档次低 →「放门卫的外卖」。
- **分数**：距离 1 分 / 10px、好回答 +100（秒选 +50）、惊险 +30、零钱 +10、和解 +300，连击倍率最高 ×2；到家剩的钱 ×10、饱腹 ×5；19:00 前每早一分钟 +100，晚一分钟 −50。
- **下班战报**（截图分享卡）：到家时间 + 评级印章、称号（借口永动机 / 职场端水大师 / 和解大师 / 社交恐怖分子……）、今晚的饭、**今日最离谱借口**（本局选过的最好笑的一句 + 当时的问题）、拦住你的人、数据。
- **分享**：标题「我 18:49 就到家吃上红烧肉了，你几点？」，带上种子和到家时间；好友点开标题页出现「好友 18:49 到家 · 跑同一条路」。

## 9. 新手引导

首局自动带教学：老刘第一题世界停住等你选（左右箭头 + 指尖示意）；第一个文件箱前定格教「上滑 / 点一下：跳」；第一条横幅前定格教「下滑：滑铲」。之后第一次被追、第一次借口用到第 2 次、第一次遇到记仇、第一次饿到 <25，各弹一次黄色提示条（记在存档里，只出一次）。标题页常驻三步图示：躲障碍 · 两秒选回答 · 别被逮 3 次。

## 11. 手感与反馈

- 起跳拉长、落地压扁，急降落地加重震屏和音效。
- 撞上障碍、被抓、掉井时世界停顿 0.06–0.12 秒。
- 脚下扬尘；连续吃硬币音调逐个升高；每 10 连击庆祝一次。
- 追兵贴近时屏幕四周泛红并有心跳声，越近越急。

## 12. 美术与音频

- **风格 A · 扁平贴纸风**（三选一对比后定稿，美术总监评分 A 8 / B 6.3 / C 5.2）：统一深紫粗描边（#2b2233）、平涂加一档硬阴影、暖色夕阳调。
- **角色**：9 个角色（主角 + 8 个 NPC）各一套 7 个部件（头、躯干、大臂、小臂、大腿、小腿、鞋）+ 3 个表情头，由程序化骨骼驱动；主角表情：平常 / 慌张（被追）/ 开心（吃饭），NPC：平常 / 生气（追人）/ 满意（放行）。
- **背景**：远景天际线条带 + 中景「楼体模块」由引擎按种子随机拼接（街道 12 块、公司 8 块、小区 8 块、楼道 6 块），室内路段垫墙色、户外路段随时钟压暮色。
- **道具**：约 40 件（障碍、地标、零钱、包子、5 种晚饭），每件按判定框对齐尺寸和锚点（`?hitbox=1` 可核对）。
- **生产管线**：AI 绘图（GPT-Image 2.5 透明底）按统一风格前缀 + 参考图链生成 → 独立美术总监验收（71 件 70 件一次通过）→ `tools/art/build.py` 打包，共 1.2MB。
- **渲染**：PixiJS（WebGL）合批，实测每帧 0.2ms（原 Canvas 2D 约 4.7ms）。
- **音频**：BGM 两首（跑酷 150 BPM 51 秒，标题和到家 48 秒，均无缝循环）；音效 WebAudio 现场合成。
- **包体**：主包约 2.6MB（4MB 上限）。
