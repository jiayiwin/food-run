# 《食为天》详细设计文档（v0.4 可玩原型）

> Project: Belly First。方向来自《下班了，我要吃饭》六方向概念文档中的 ③「反向恋爱养成」。
> 缝合点：**恋爱养成的壳**（立绘、好感条、三选一对话、粉色 UI、结算评级）× **下班回家吃饭的核**（所有数值反着来：你要让每个人都"不太在意你"）。
> 本文是数值与规则定稿，原型代码以本文为准；改规则先改本文。

## 1. 一句话

> 名字：《食为天》（取「民以食为天」），副标题「别理我，饭要凉了」。曾用名《请不要关注我》《别看我，我要吃饭》。

恋爱游戏是把好感养到 100。这个游戏里每个人都有一条 **注意力条（0–100）**，你的目标是让所有人都停在 **30–70 的「不太在意你」区间**：太高了他们缠住你，太低了他们觉得被冷落、回头找你麻烦。一路从公司走回家，吃到那口饭。

## 2. 范围（v0.2）

| 包含 | 不包含（后续版本） |
|---|---|
| 完整单局：3 幕 9 个时段、15 个对话场景、1 个来电场景 | 局外成长 / 解锁 |
| 5 个 NPC，各有注意力性格、缠人后果、冷落后果 | 多结局 CG、语音 |
| 注意力三区间管理、±8 随机波动、甩锅连锁 | 商店 / 道具 |
| 地点二选一（恋爱游戏的"去哪儿"界面） | 每日种子排行榜（需后端） |
| 结算评级「今日关注度管理」S/A/B，断线续局 | 美术资源（原型用 emoji 立绘）、音效 |

技术：纯前端 HTML + 原生 ES Module，无构建步骤，手机竖屏优先。逻辑层不碰 DOM，后续可直接搬进微信小游戏。

## 3. 核心循环

```
时段开始 → （有麻烦先处理：怨气事件 / 妈的来电）→ 选地点（二选一，看得见那里是谁、他现在多在意你）
      → 对话场景 2 个节拍，每拍三选一，选项标注预期注意力变化
      → 场景结束判定：安全区「完美」/ 过热「被缠住」/ 过冷「冷场」
      → 时段结算：注意力漂移、传染、怨气累计、饥饿 −4
      → 下一时段 … → 家门 → 吃到了（或饿晕）
```

单局 9 个时段、约 18 次选择，12–20 分钟。

## 4. 资源系统

### 4.1 注意力（每个 NPC 一条，0–100）

| 区间 | 名称 | 效果 |
|---|---|---|
| > 70 | 过热 | 场景结束时**缠住你**（见 NPC 表），每个时段都会传染给话痨同事；只要场上有人过热，这一场就不算「完美」 |
| 30–70 | 安全 | 主角 NPC 在安全区且无人过热 → 判「完美」，计入评级 |
| < 30 | 过冷 | 时段结束**怨气 +1**（小林 +2）；怨气 ≥ 2 触发**麻烦事件**，然后清零并把注意力拉回 50 |

- 怨气在 NPC 回到安全区或过热区的时段清零（只要你给了关注，气就消了）。
- 每个选项的注意力变化先过 NPC 性格修正，再加 **±10 的均匀随机波动**。界面显示修正后的预期值，不显示波动。
- **冷落衰减**：这个时段没见到的人，注意力 −4。五个人只能照顾一个，久不理谁，谁就滑向过冷 → 怨气。这是「养成」那一半的调度核心。
- 选项分三类：**A 热情型**（大幅 +，恋爱游戏的"正确答案"，这里是陷阱）、**B 敷衍型**（小幅 −，安全）、**C 甩锅型**（自己 −，把注意力转给第三人 +）。

### 4.2 饥饿值（0–100，开局 100）

| 事件 | 变化 |
|---|---|
| 每个时段结束 | −6 |
| 停下来陪聊的选项 | −2 ~ −6（选项上标注） |
| 被缠住（场景结束时过热） | −6 ~ −20（见 NPC 表） |
| 麻烦事件 | 0 ~ −12 |
| 小林的关东煮 | +8 |

归零即败：「饿晕在路上」。预算：9 × 6 = 54，选项约 −20，事故约 −15，到家剩 10–30。贪心 AI 200 局：平均剩 32。

## 7. 结局与评级

到家门场景结束后：
- 妈过热：「坐下，先跟妈说说今天」饥饿 −15，计 1 次事故。
- 之前触发过「连打 5 个电话」：「饭凉了，妈默默去热」饥饿 −8。
- 此时饥饿 ≤ 0 → 「在饭桌前饿晕了」判负。
- 其他人过热各出一条结局彩蛋：老板「明天早点来」/ 小林「到家了吗？」/ 小张 47 条语音 / 老师拉你进返校分享群。

**评级「今日关注度管理」**：S = 零事故且完美 ≥ 8 场；A = 事故 ≤ 2；B = 其他。失败：「饿晕」。

## 8. 视觉与反差

- UI 全程照搬恋爱游戏：粉色渐变、圆角白卡、心形 → 换成眼睛 👁 作注意力图标、立绘脸红、选项带闪光。
- 文案全部反向：选项标「注意力 −8」而不是「好感 +10」；安全区弹「完美回避！」撒花；过热弹红色「危险！注意力过高！」；甩锅成功弹「风险转移成功」。
- 结算界面是粉色的「今日关注度管理：S 级」。

## 9. 张力机制（v0.3 补丁）

v0.2 试玩反馈：「每一步有标准答案、没反馈、每场一个样」。v0.3 针对性加四件事，逻辑层与场景数据全部复用。

| 机制 | 规则 | 目的 |
|---|---|---|
| **藏数字** | 选项不再显示预期注意力变化，只显示饥饿代价。选完进入「反应」阶段：大表情、注意力条位移动画、飘字（此时才显示实际变化）、每个在场者一句反应台词。 | 把算术题变成读人：热情 / 敷衍 / 甩锅只能从文案判断，结果看脸色。 |
| **倒计时** | 每拍限时：第 1 幕 6 秒、第 2 幕 5 秒、第 3 幕 4.5 秒、来电 4 秒。最后 2 秒屏幕抖动、音效加急。超时 = 「慌了」随机选，权重热情 50% / 敷衍 20% / 甩锅 30%。慌选次数计入结算。 | 借方向 ⑥ 的实时压力；陷阱选项在慌乱中更容易中招。 |
| **多人同场** | 场景可带旁观者（工位有小张、大门口有小林、公交站有小林）。旁观者被你对主角的态度带动：变化 = 主角实际变化 × 0.4。甩锅给在场的人：他听见了，效果 × 1.5，并当场反应。场景结束时在场的其他人若过热，也会缠你（代价减半）。 | 甩锅有了真实对象在旁边看着；一句话影响多条。 |
| **闯入** | 第 2 拍开始前：若有人过热且不在场，60% 概率他主动闯进来；否则 20% 概率随机路人闯入。闯入者加入在场，本拍起生效。 | 让「过热的人会主动找你」这条规则被看见。 |
| **音效** | WebAudio 合成：滴答、加急、完美、危险、冷场、慌了、闯入、胜负。可静音。 | 零素材的即时反馈。 |

键盘：A/B/C 或 1/2/3 选项，空格 / 回车继续。

## 10. 任务与表现层（v0.4）

v0.3 试玩反馈：「没有任务、立绘、动效、音乐，全是平面文字」。v0.4 补齐表现层，逻辑层只加了任务系统。

### 10.1 今日任务

每局开局从任务池随机抽 3 个，选地点界面和场景小结里实时显示（已经不可能完成的打 ✗），结算时判定，每完成一个 +1 ★。任务池（`src/data/tasks.js`）：

| 任务 | 判定 |
|---|---|
| 老板全程没留下你 | 事故记录里没有「再说两句」「加班」 |
| 甩锅至少 3 次 | transfers ≥ 3 |
| 一次都没慌 | panics = 0 |
| 到家时小林 / 小张刚好不太在意你 | 结算时在安全区 |
| 妈没有连打五个电话 | 未触发 momAngry |
| 完美回避 5 场 | perfect ≥ 5 |
| 到家时饥饿还剩 30 以上 | hunger ≥ 30 |
| 没被老师留下补课 | 事故记录里没有「补课」 |
| 没人回头找你麻烦 | 没触发任何怨气事件 |

### 10.2 美术

- **立绘**：5 个 NPC 各一张「三表情设定表」（过热 / 安全 / 过冷并排），日系恋爱养成风、赛璐璐上色、透明底。用 GPT-Image 2.5 一张图出三个表情保证同一角色一致；PIL 清理透明光晕（alpha ≥ 250 为核心、膨胀 3px 保留抗锯齿、其余清零），按人物切三栏重排成严格三等分，再按连通域去掉邻栏碎片；导出 1536×864 WebP（约 250KB）。前端用 CSS 精灵按区间切换表情（`--col` 0/1/2），缺图自动退回 emoji。源 PNG 在 `assets/src/`。
- **背景**：办公室 / 大厅 / 街道 / 家门 / 标题 5 张 9:16 竖屏，傍晚暖光、轻微虚化，JPG 约 200KB。双层交叉淡入 + 40 秒缓慢漂移；上面压一层粉色渐变保证文字可读。
- **音乐**：AI 音乐模型 生成两轨 160 秒纯音乐：平静版（尤克里里 + 钢琴，100 BPM）和紧张版（130 BPM，心跳低音）。有人过热或倒计时最后 2 秒切到紧张版，交叉淡入淡出；首次点击后才开始播放；和音效共用一个静音开关。
- **动效**：界面淡入上滑、台词打字机、选项依次滑入、表情切换弹跳、注意力条位移动画、飘字、危险震屏、完美撒花（Canvas 粒子）、标题樱花飘落、胜利撒花。全部响应 `prefers-reduced-motion`。

### 10.3 实时合格线与文案风格（v0.4.1）

- 试玩反馈：「实时信息看不到什么标准是合格的」。每拍在立绘下方常驻一条**合格线**：规则一句话（说完时 TA 在「刚好」，在场没人「太热」）+ 在场每人的实时判定（✓ 刚好 / ✗ 太热，会拉住你，饭要凉 / ✗ 太冷，会记仇，回头找你）+ 此刻结论（合格 / 不合格并指出是谁）。区间名改为 **太热 / 刚好 / 太冷**，注意力条下方直接标「目标：刚好」。
- 文案风格：职场黑话（对齐颗粒度、闭环、抓手、赋能、画饼、PUA）、网络梗（胆子肥嘟嘟、尊嘟假嘟、偷感很重、淡淡的死感、硬控、CPU、已读乱回、蚌埠住了、家人们谁懂啊、活人感、松弛感、City 不 City、上岸、牛马、脆皮打工人、精神离职、显眼包、退退退、芭比Q、破防、磕到了、我不理解但我尊重）、短剧梗（战神回家、重生之我在楼下等你、霸总 BGM 当铃声）。分配原则：老板说黑话，小张说热搜，小林偷感，老师问上岸，妈看短剧；玩家选项里的热情型用「胆子肥嘟嘟」这类自嘲。

### 10.4 道具与路人（v0.5）

试玩反馈：「别都是熟人，可以出现动物、陌生人；都是点选择，没有道具、攻击、防御吗」。

**道具栏**（最多 3 个，开局随机 1 个，倒计时里随时点、立刻生效，用完即消失）：

| 道具 | 类 | 效果 |
|---|---|---|
| 😷 口罩 | 攻 | 本场主角的正向变化 ×0.5 |
| 🎧 耳机 | 攻 | 主角注意力 −10 |
| 📨 急事短信 | 攻 | 主角 −20，在场其他人 +5 |
| 🔋 充电宝 | 防 | 下一次被缠住不扣饥饿、不算事故 |
| 🕶️ 墨镜 | 防 | 本场旁观者不被带动 |
| 🍢 关东煮 | 补 | 饥饿 +10 |
| ☕ 咖啡 | 时 | 本拍倒计时 +5 秒 |

**路人与动物**（7 个：流浪猫、小区柯基、发传单小哥、问路大爷、广场舞阿姨、外卖小哥、借手机的陌生人）：二选一的时段有 50% 概率出现第三个「路人」选项。路人是一拍场景，注意力每次从 50 起，不进常驻名单（无冷落衰减、怨气、闯入）。处理得「刚好」掉该路人专属道具（关东煮 / 咖啡 / 墨镜 / 充电宝 / 耳机）；太热会被硬控扣饥饿 5–7（广场舞阿姨还会把照片发给你妈：妈 +12）。代价：去见路人这一时段所有熟人都没见到，各 −4。

### 10.5 一屏布局（v0.5.1）

试玩反馈：「一屏幕都放不下，要反复拖动滚动条」。整个游戏固定在 100dvh 内、页面不滚动：HUD 吸顶、立绘高度按屏幕高度缩放（24dvh，≤700px 高时 20dvh）、开场白并进对话气泡（矮屏隐藏）、合格线压成一行、旁观者缩成小头像、道具栏图标化横滑、选项紧凑。只有选地点、结算、通知三页允许在自己区域内滚。用无头 Chrome 套 iframe 的方式验证过 390×844、430×932、375×667 三种视口。

### 10.6 招数与动物闯入（v0.6）

试玩反馈：「没看到动物；只能短暂对话，不能用招躲过或借他人支走威胁吗」。

**三个招数**（倒计时里随时用，不消耗对话拍，可与选项叠加）：

| 招 | 效果 | 限制 |
|---|---|---|
| 👻 装透明 | 尝试直接溜走：主角刚好 75% / 太冷 60% / 太热 35% 成功。成功 → 场景立刻结束并按当前区间结算；失败 → 主角 +12「被抓包」 | 每场 1 次 |
| 👉 支走 | 点名任意一个人当借口（常驻 NPC 或在场路人）：主角 −15，被点名的 +15（在场则 ×1.5 且当场反应） | 每天 3 次 |
| 🧱 装忙 | 这句不接话，直接跳过：谁的注意力都不变，不算完美也不断连击；饥饿 −3 | 每场 1 次 |

支走的策略：把太热的人支去缠别人，或者把注意力引到冷落已久的人身上顺便给他回暖，一举两得；代价是被点名的人下次见面更热。

**动物闯入**：第 2 拍若没有人类闯入，30% 概率流浪猫或柯基闯进来当旁观者（注意力 50 起），会被你的态度带动，场景结束时过热就缠你（代价减半）。路人选项出现率 50% → 75%，抽取时动物权重 ×2。

### 10.7 路人小游戏与节奏（v0.7）

试玩反馈：「陌生人和动物没有活物感，不能只有文字选择；节奏有点快，没看清就过去了」。

- **动物 → 「摸一下就走」**（按住）：按住动物，注意力条 2.2 秒涨满，动物随之放大、抖动、发光；在「刚好」区间（30–70）松手 → 刚好、掉道具；松早了过冷（它哈气）；松晚了过热（被硬控扣饥饿）；9 秒内不松手按当前值算、从没按过按 15 算并扣饥饿 4。
- **陌生人 → 「擦肩而过」**（时机）：对方目光 👀 在轨道上以约 4 秒一个来回扫，中段红区 = 在看你、两侧绿区 = 看别处。绿区按「走」→ 刚好（50）；红区按 → 太热（82，被叫住）；9 秒不按 → 太冷（20）并扣饥饿 4「干站着」。
- 小游戏结算后复用路人的场景结束逻辑（掉道具 / 硬控 / 冷场文案），不再有三选一。
- **活物感**：路人与动物立绘常驻呼吸 / 摇晃动画；小游戏里按住时动物放大旋转、陌生人随目光转头。
- **节奏**：每句倒计时 6 / 5 / 4.5 秒 → 10 / 8.5 / 7.5 秒，来电 7 秒，第一句再 +3 秒看开场白；反应页不再自动翻页，看完自己点「继续」（或空格）。

### 10.8 今晚的饭（v0.8）

试玩反馈：「吃上没吃上都把要吃的饭放出来，随机，状态不一样」。开局从 10 道家常菜里随机一道（红烧肉、番茄炒蛋、热汤面、饺子、麻辣小龙虾、糖醋排骨、咖喱饭、小火锅、可乐鸡翅、蛋炒饭），选地点页和家门场景会提「今晚妈做了 X」当盼头。结算页不论胜负都把这道菜端出来：

| 状态 | 条件 | 表现 |
|---|---|---|
| ♨️ 刚出锅 | 赢，S / A 级，妈没留你聊天 | 热气动画，专属「真香」文案 |
| 🌡️ 温的 | 赢，B 级，或被妈留下聊了二十分钟 | 淡热气，「有点坨了」 |
| 🧊 凉了 | 赢，但之前触发过「连打五个电话」 | 蓝调、去饱和，「妈端去热了」 |
| 💭 梦里的 | 饿晕 | 灰、虚、带💭，梦境文案 |

每道菜四段文案在 `src/data/meals.js`。

### 新手引导（v0.9）

试玩反馈：「前几次上来不知道干啥，就是一顿点对话」。原因是选项看不出后果，规则只在标题页一段长文字里。三处改动：

- **选项后果标签**：每个选项后面标出会动到谁、往哪边走——`老板↑` 升温、`老板↓` 降温，变化 ≥18 用双箭头，动到非主角用虚线框。只给方向不给数字，按 `expectedDelta` 算（已含特质和词条）。
- **情境引导**：第一次遇到某样东西时弹一条聚光灯提示，每条只出一次，可「跳过全部引导」，标题页「进阶玩法」里可重看。弹提示时倒计时冻结。顺序：注意力条 → 选项箭头 → 倒计时 → 饥饿（第一句）；完美判定与合格线（第一次反应）；三招（第二句）；旁观者；选路；小林情绪箭头；道具；事件牌。引导上线前已经赢过的老玩家不再弹。
- **标题页三步图示**：看条 / 选话 / 回家吃饭，进阶内容折叠。普通难度前两局每句多 3 秒。

## 11. 验收标准（v0.8）

1. 贪心 AI 200 局胜率 ≥ 70%、S 级占比 < 40%；随机 AI 200 局不崩溃，胜率 < 50%。（v0.3 当前：贪心 95.5% / S 16% / 平均 2.8 次事故，随机 7%。AI 不受倒计时影响，真人会更低。）
2. 老板正向变化 ×1.5；老师所有变化 ×0.6，过热时负向再 ×0.5。
3. 任意 NPC 连续两个时段过冷 → 麻烦事件触发、注意力归 50、怨气清零。
4. 妈过冷 → 下一时段先来电；不接两次 → 「连打 5 个电话」且到家饭凉。
5. 小林过热 → 下一场景「跟着你」，主角 NPC 的变化 +5。
7. 这个时段没见到的 NPC 注意力 −4；场上有人过热时主角安全区不计「完美」。
8. 甩锅给在场的人效果 ×1.5 并出反应台词；旁观者变化 = 主角实际变化 × 0.4。
9. 超时慌选计入统计；反应阶段不能再选。
10. 有人过热时第 2 拍闯入概率接近 60%；闯入者进入在场列表。
11. 每局 3 个今日任务，结算判定并计 ★；缺图退回 emoji，缺音乐不报错。
12. 道具：口罩 ×0.5、急事短信 −20/+5、充电宝免罚一次、咖啡 +5 秒；反应阶段不能用。
13. 路人出现率接近 75%，不进常驻名单，刚好时掉道具。
14. 装透明成功率按区间；支走 −15/+15（在场 ×1.5）每天 3 次；装忙跳过这句、注意力不变。
15. 没人过热时动物闯入率接近 24%，动物不进常驻名单。
16. 路人进入小游戏而非对话；松手值即注意力；超时扣饥饿 4；只能结算一次。
17. 开局随机一道饭；结算状态：S/A 刚出锅、B 或被妈留下为温、饭凉事件为凉、饿晕为梦。
6. 刷新页面后可从标题页「继续上局」。
18. 每个选项显示后果方向标签；新玩家首局第一句弹引导且倒计时冻结，每条引导只出一次。
