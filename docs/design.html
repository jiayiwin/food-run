《食为天》—— 反向恋爱养成详细设计

从《下班了，我要吃饭》六方向中选定方向 ③，定名《食为天》（曾用名《请不要关注我》《别看我，我要吃饭》），副标题「别理我，饭要凉了」。本页是数值与规则定稿，与仓库 docs/GDD.md 同步；可玩原型按此实现。

恋爱游戏是把好感养到 100。这个游戏里每个人都有一条注意力条，你的目标是让所有人都停在 30–70 的「不太在意你」区间：太高了他们缠住你，太低了他们觉得被冷落、回头找你麻烦。一路从公司走回家，吃到那口饭。

核心循环

时段开始→先处理麻烦 / 妈的来电→选地点（二选一，看得见是谁、他多在意你）→对话 2 拍，每拍三选一→场景判定：完美 / 被缠住 / 冷场→时段结算：漂移、传染、冷落、怨气，饥饿 −6→家门→吃到了
两层决策。选地点是养成游戏的日程管理：五个人只能照顾一个，热的别凑、冷的去哄。选对话是反向好感：热情选项是陷阱，敷衍是安全，甩锅把注意力转给第三人。

结局与评级

家门场景结束后妈过热：「坐下，先跟妈说说今天」饥饿 −15，计 1 次事故 · 之前触发过连打 5 个电话：「饭凉了」饥饿 −8 · 此时饥饿 ≤ 0 → 「在饭桌前饿晕了」判负。
结局彩蛋其他人过热各出一条：老板「明天早点来」· 小林「到家了吗？」· 小张 47 条语音 · 老师拉你进「优秀毕业生返校分享」群。
评级「今日关注度管理」S = 零事故且完美 ≥ 8 场 · A = 事故 ≤ 2 · B = 其他 · 失败 = 饿晕。

张力机制（v0.3 补丁）

v0.2 试玩反馈：每一步有标准答案、没反馈、每场一个样。v0.3 针对性加四件事，逻辑层与场景数据全部复用。
藏数字选项不再显示预期变化，只显示饥饿代价。选完进入「反应」阶段：大表情、注意力条位移动画、飘字（此时才显示实际变化）、在场每人一句反应台词。把算术题变成读人。
倒计时每拍限时：第 1 幕 6 秒、第 2 幕 5 秒、第 3 幕 4.5 秒、来电 4 秒。最后 2 秒屏幕抖动、音效加急。超时 = 「慌了」随机选，权重热情 50% / 敷衍 20% / 甩锅 30%，陷阱在慌乱中更容易中招。
多人同场场景可带旁观者（工位有小张、大门口有小林、公交站有小林）。旁观者被你对主角的态度带动：变化 = 主角实际变化 × 0.4。甩锅给在场的人：他听见了，效果 × 1.5 并当场反应。场景结束时在场的其他人若过热，也会缠你（代价减半）。
闯入第 2 拍开始前：若有人过热且不在场，60% 概率他主动闯进来；否则 20% 概率随机路人闯入。「过热的人会主动找你」这条规则从后台走到台前。
音效与键盘WebAudio 合成滴答 / 加急 / 完美 / 危险 / 冷场 / 慌了 / 闯入 / 胜负，可静音。键盘 A/B/C 选项，空格继续。

任务与表现层（v0.4）

v0.3 试玩反馈：没有任务、立绘、动效、音乐，全是平面文字。v0.4 补齐表现层，逻辑层只加了任务系统。
今日任务每局从 10 个任务里随机抽 3 个（老板全程没留你 / 甩锅 ≥ 3 次 / 一次都没慌 / 到家时小林在安全区 / 妈没连打五个电话 / 完美 5 场 / 饥饿剩 30+ / 没被老师补课 / 没人找麻烦 …）。选地点界面实时显示，不可能完成的当场打 ✗，结算每完成一个 +1 ★。
立绘5 个 NPC 各一张「三表情设定表」：过热 / 安全 / 过冷并排，一张图出三个表情保证同一角色一致。GPT-Image 2.5 透明底 → PIL 清理光晕、按人物切三栏重排、连通域去碎片 → 1536×864 WebP 约 250KB。前端 CSS 精灵按区间切换表情，缺图退回 emoji。
背景与音乐5 张 9:16 傍晚场景（办公室 / 大厅 / 街道 / 家门 / 标题），双层交叉淡入、缓慢漂移。AI 音乐模型 生成平静（100 BPM 尤克里里钢琴）与紧张（130 BPM 心跳低音）两轨 160 秒纯音乐，有人过热或倒计时最后 2 秒交叉切换。
动效界面淡入、台词打字机、选项依次滑入、表情弹跳、注意力条位移、飘字、危险震屏、完美撒花、标题樱花、胜利撒花；全部响应 prefers-reduced-motion。
一屏布局整个游戏固定在 100dvh 内，页面不滚动：立绘高度按屏幕缩放、开场白并进气泡、合格线一行、旁观者小头像、道具栏横滑。只有选地点、结算、通知三页在自己区域内滚。390×844 / 430×932 / 375×667 三种视口验证过。

试玩反馈：别都是熟人，可以出现动物、陌生人；都是点选择，没有道具、攻击、防御吗。
道具类效果
😷 口罩攻本场主角的正向变化 ×0.5
🎧 耳机攻主角注意力 −10
📨 急事短信攻主角 −20，在场其他人 +5

🍢 关东煮补饥饿 +10

道具栏最多 3 个，开局随机 1 个，倒计时里随时点、立刻生效、用完消失。来源只有路人和动物。
三个招数倒计时里随时用、不消耗对话拍：👻 装透明（直接溜走，刚好 75% / 太冷 60% / 太热 35%，失败被抓包 +12，每场一次）· 👉 支走（点名任何人当借口：主角 −15，被点名 +15，在场 ×1.5 并当场反应，每天 3 次，可以把太热的人支去缠别人）· 🧱 装忙（本拍正向归零，饥饿 −3，每场一次）。
路人小游戏动物是「摸一下就走」：按住它注意力条往上涨、它越来越兴奋，在「刚好」松手；陌生人是「擦肩而过」：对方目光在轨道上来回扫，趁看别处时按「走」，红区按被叫住，不按干站着凉掉。立绘常驻呼吸和摇晃。
节奏每句倒计时 10 / 8.5 / 7.5 秒，第一句再 +3 秒；反应页不自动翻，看完自己点。
今晚的饭开局随机一道家常菜（10 道），路上当盼头提两次；结算不论胜负都端出来：S/A 刚出锅冒热气、B 或被妈留下聊天是温的、挂过妈电话是凉了端去热、饿晕是梦里的灰色那盘。
路人与动物流浪猫、小区柯基、发传单小哥、问路大爷、广场舞阿姨、外卖小哥、借手机的陌生人。二选一的时段 75% 概率多出第三个选项（动物权重 ×2）；第 2 拍没人闯入时 30% 概率猫或狗闯进来当旁观者；一拍场景，注意力每次从 50 起，不进常驻名单。处理得「刚好」掉专属道具；太热被硬控扣饥饿；广场舞阿姨会把照片发给你妈。代价：去见路人，这一时段的熟人都没见到，各 −4。

视觉与反差

UI 全程照搬恋爱游戏：樱花粉渐变、圆角白卡、立绘脸红、选项闪光；心形换成眼睛 👁 作注意力图标。文案全部反向：选项标「注意力 −8」而不是「好感 +10」；安全区弹「完美回避！」撒花；过热弹红色「危险！注意力过高！」；结算是粉色的「今日关注度管理：S 级」。原型用 emoji 代立绘，正式美术另出。

v0.2 → v0.3：贪心 S 级从 19.5% 降到 16%，B 级从 0.5% 升到 37.5%，随机通关从 28.5% 跌到 7%——多人同场和闯入让一句话牵动多条。AI 看得见预期值且不受倒计时影响，真人成绩会更低，这是故意的：难点在拿 S，瞎点必饿晕。调参杠杆依次是：倒计时长度、旁观者带动比例、时段饥饿、缠住代价。

验收标准（v0.2）

  1. 贪心 AI 200 局胜率 ≥ 70%、S 级 < 40%；随机 AI 200 局不崩溃、胜率 < 50%。自动化测试
  2. 老板正向 ×1.5；老师 ×0.6，过热时负向再 ×0.5。自动化测试
  3. 连续两个时段过冷 → 麻烦事件、注意力归 50、怨气清零。自动化测试
  4. 妈过冷 → 下一时段先来电；按掉两次 → 连打 5 个电话且到家饭凉。自动化测试
  5. 小林过热 → 下一场景跟着你，主角 NPC 的变化 +5；主角是小林时不生效。自动化测试
  6. 随机波动在 ±10 内；场景数据与反应台词完整。自动化测试
  7. 甩锅给在场的人 ×1.5 并出反应台词；旁观者变化 = 主角实际变化 × 0.4。自动化测试
  8. 超时慌选计入统计；反应阶段不能再选。自动化测试
  9. 有人过热时第 2 拍闯入概率接近 60%；在场他人过热也会缠你。自动化测试
  10. 刷新页面后可从标题页「继续今天」。存档往返测试
