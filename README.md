# 狂奔吧，打工人

微信小游戏：横版跑酷 + 限时二选一。18:00 下班，躲开障碍、用两秒编好借口，别被同事追上，回家吃上热饭。

策划案见 [docs/GDD.md](docs/GDD.md)。

## 技术栈

| 层 | 用的什么 |
|---|---|
| 平台 | 微信小游戏原生（`game.js` 入口），JavaScript ES 模块 |
| 渲染 | **PixiJS 7（WebGL）**，按需打包在 `js/libs/pixi.js`（约 336KB）；WebGL 起不来自动退回 Canvas 2D |
| 绘制接口 | `js/gfx/`：即时绘制接口（按调用顺序画），底层复用精灵池直接提交 WebGL 批处理；矢量画第一次用到时烘焙成贴图 |
| 角色 | 程序化骨骼（关节角度 → 姿势），每个部件一张贴图（AI 美术或烘焙的矢量画），三种表情头 |
| 美术 | 扁平贴纸风（A），AI 出图 → `tools/art/build.py` 清理光晕 / 切片 / 后处理（外圈、换色、背景调色）/ 打包 → `art/` + `js/data/art.js` |
| 音频 | 2 首 BGM（跑酷 / 标题和到家，mp3 循环）+ WebAudio 实时合成音效 |
| 逻辑 | 纯 JS，可复现（种子随机数），每帧按真实时间切成 ≤1/60 秒的小步推进 |

## 在微信开发者工具里跑

1. 打开微信开发者工具 → 导入项目 → 选本目录（`project.config.json` 里是游客 appid，正式发布换成自己的）。
2. 项目类型是「小游戏」，入口 `game.js`。本地设置里保持「ES6 转 ES5」「增强编译」打开。
3. `dev/`、`tools/`、`test/`、`docs/`、`art-src/` 已在打包时忽略，主包约 2.9MB（上限 4MB，`npm test` 里有检查）。
4. 第一次真机测试按 [docs/微信首测清单.md](docs/微信首测清单.md) 过一遍。开发版和体验版左下角显示渲染方式和帧率，报错会弹窗。

## 在浏览器里调试（不用开发者工具）

```
npm run dev          # http://localhost:5173/dev/
```

`dev/wx-shim.js` 在浏览器里模拟了用到的 `wx.*` 接口，游戏代码不用改。键盘：↑/空格 跳（电梯轿厢里是关门键）、↓ 滑铲、←/→ 选（没有卡片时 → 是冲刺：被追时、或路口闪绿 / 电梯门前脚下有 ▶▶ 才生效）、1/2/3 便利店、P 暂停。

调试参数（加在 `/dev/` 后面）：

| 参数 | 作用 |
|---|---|
| `?w=375&h=812&notch=1` | 模拟屏幕尺寸和刘海 |
| `?scene=play&seed=5` | 直接开一局（固定种子） |
| `&level=full` | 按哪一关开局（`js/data/levels.js`：`full` 自由下班、`prologue` 序章、`mon` / `tue` / `wed` 周一到周三；不认识的 id 按自由下班） |
| `&assist=1` | 带薪摸鱼（只在关卡里有：读题 +0.3 秒、随机段障碍少 15%、这一局最多两星） |

| `?scene=title` | 标题页，和不带 `scene` 一样：存档还没选过主角（新玩家、`save=new` / `old`）时照样先到选主角页，加 `&gender=m` / `f` 直接到标题页 |
| `&gender=m` / `f` | 这次用男 / 女主角（只在内存里，不写存档、不弹选主角页） |
| `&story=cat.catfood` | 家庭剧本的故事（`家庭.故事`，见 `js/data/family.js`：`parents` / `share` / `cat` / `kid` / `nainai` 和它们的故事）；关卡里以关卡写死的为准；不写按规则抽 |
| `&save=new` / `old` | 当成新玩家 / v1 老玩家（只在内存里，不覆盖本地存档）：看标题页「下班！」去哪、选关页的锁；两种都还没选主角，先到选主角页 |
| `&tutorial=1` | 新手局 |
| `&xlight=red` / `green` / `flash` / `worst` | 覆盖斑马线路口的灯态（全红 / 全绿 / 全闪绿 / 前两个红、其余闪绿），路不变 |
| `&route=lift` / `stairs` | 路线卡：机器人坐电梯 / 走楼梯（机器人缺省坐电梯）；人玩时是超时默认走哪条（缺省楼梯） |
| `&bot=1` / `2` / `3` / `4` | 机器人代打：老手 / 完美 / 完美操作但每题选错（被追时冲刺）/ 每题选错且从不冲刺（看鞋底提示环） |
| `&gfx=canvas` | 强制用 Canvas 2D 后端（对照 / 兜底测试） |
| `&wxstrict=1` | 藏掉微信里没有的 DOM 全局变量，检验渲染层不依赖它们 |
| `&hitbox=1` | 显示判定框（障碍红、主角绿），核对美术图和碰撞 |
| `&debug=1` | 浏览器里也显示开发版信息：左下角帧率、结算页顶上的滑动 / 冲刺埋点（冲刺次数、冲刺后 1 秒内撞上几次；点一下复制成一行 JSON） |
| `&daily=1` | 按今日挑战开局（带每日词条；`seed=2` 是暴雨） |
| `?seed=5&t=18:52&d=0&lv=full&cv=6&h=share.tissue` | 模拟点开好友的分享卡（不带 `scene`）：标题页出好友卡，点它跑同一条路、回同一个家；`lv=tue` 是关卡卡（不带 `h`）、`a=1` 好友开了带薪摸鱼。屏幕尺寸只认纯数字的 `w` / `h`，`h=家.故事` 照常当好友卡参数 |
| `&art=/dev/art-candidates/A/manifest.json` | 换一份美术清单（对比风格） |
| `?gallery` `?scenery` `?props` | 旧版矢量人物姿势、场景、障碍陈列（`dev/legacy/`） |

截图（无头 Chrome，精确手机视口；发布前 812 刘海屏和 667 矮屏都要看）：

```
node tools/shot.mjs out --w 375 --h 812 --notch --url "/dev/?scene=play&seed=3&bot=1" --script steps.json
```

steps.json 支持 `wait` / `key` / `tap` / `hold`（`[x, y, 毫秒]` 按住）/ `swipe` / `eval` / `shot`；`swipe` 写方向（`"up"`）或总位移（`[28, -24]`，测斜划）；`eval` 里可以用 `__game.scene.skip(秒, 条件)` 快进到想看的时刻，`__game.go(场景, 参数)` 换场景；要逐帧核对时把 `__game.scene.update` 临时换成空函数冻住世界（画面照常刷新），看完再换回来。每次截图都是全新的浏览器存档，适合从新玩家开始一路点下去。

## 美术管线

```
python tools/art/build.py build art-src/spec.json    # 原图 → art/（游戏用）+ js/data/art.js（清单）
node tools/balance.mjs --family [--n 200]            # 家庭剧本：每个故事 × 3 档机器人的门口分布、钩子办成率、晚饭、称号、世界停住，最后按验收线打勾（--story share.takeaway 只跑一个）
python tools/art/build.py slice <部件表.png> <目录>   # 把部件表 / 楼体表切成单块
python tools/art/build.py clean <in.png> <out.png>   # 去掉 AI 透明底的灰色光晕
node tools/build-libs.mjs                            # 重新打包 PixiJS
```

`art-src/spec.json` 写每张图在游戏里的尺寸、锚点和角色部件顺序；清单为空时游戏全部回退到代码绘制。角色的 `pivots` 里写 `head_normal` / `head_panic` / `head_happy` 时，表情头按这里的半径归一（女主角 `playerF` 用它让脸和男主角一样大），不写按缺省。

可读性相关的字段（打包时后处理，不用重新出图）：

| 字段 | 写在哪 | 作用 |
|---|---|---|
| `rim: "ground"` / `"float"` | 道具 | 米白外圈（顶层 `rimPx` / `rimColor`）。会撞的和能捡的才加；落地的底边不加，悬空的四边都加。清单里写 `rim: 1.5`、`bbox`（不含外圈的内容包围盒） |
| `fix` | 道具、模块组（按文件名） | 原图分辨率上换色：`hue`（色相旋转，明暗台阶保留）、`desat`（去饱和成剪影）、`erase` |
| `post` | 道具 | 成品分辨率上重画：`rope`（遛狗绳）、`tread`（台阶踏步边） |
| `grade` | 中景、背景类道具 | 降饱和、压明度、背景描边换成同色系深色（粗墨线留给前景） |
| `skip` | 模块组 | 剔除像障碍的背景模块 |
| `backdropFull` | 中景 | 模块背后整块铺墙色（楼道） |
| `veil` | 中景 | 抄一份 `js/data/tune.js` 的 `VEIL`，只用来算跳跃带指标 |
| `dy` | 中景 | 中景往上抬，地面线上面露出一条后人行道 |
| `flip` / `anchors` | 道具 | 打包前左右镜像（违停车复用私家车的图）；锚点按比例写、清单里换算成相对绘制原点的逻辑 px（车灯 `head` / `tail`、车门铰链 `hinge`） |

马路上的车（`car_sedan` / `car_taxi` / `car_suv` / `car_van`）是一张 AI 出图的合图切开的（`art-src/props/traffic/`），打包时 `grade` 压暗、不加外圈；`carParked` 是私家车翻转 + 街道背景调色；`cardoor` 单独出图、加外圈。

打包还会：同一张远景只存一份；删掉清单没引用的旧图；写 `tools/art/report.json`（障碍主色扇区、背景跳跃带指标，测试读它）；跳跃带超标直接报错；源图还没有的条目跳过（运行时走代码兜底）。
