# Project: Belly First — 《食为天》

反向恋爱养成 × 下班回家吃饭。恋爱游戏是把好感养到 100；这里每个人都有一条注意力条，你要让所有人都停在 30–70 的「不太在意你」区间：太高了缠住你，太低了找你麻烦。一路从公司走回家，吃到那口饭。

方向来源：《下班了，我要吃饭》六方向概念文档中的 ③。详细规则与数值见 [docs/GDD.md](docs/GDD.md)。

## 运行

纯前端，无构建步骤，无依赖。

```
npm run dev        # 本地静态服务器 → http://localhost:5173/
npm test           # 验收用例 + 随机 / 贪心 AI 各 200 局模拟
```

直接双击 `index.html` 不行（ES Module 需要 http），请用 dev 服务器或任意静态服务器。

调试入口：`/#demo-scene`、`/#demo-react`、`/#demo-pick`、`/#demo-summary` 用固定种子直接进入对应界面。截手机尺寸图：无头 Chrome 的窗口最小宽度约 500，直接 `--window-size=390,844` 会被裁切；把页面放进 390×844 的 iframe 再截整页，并用 `--timeout` 等真实时间让动画播完。

## 规则一页纸

- 每个 NPC 一条注意力 0–100。>70 过热：场景结束缠住你（扣饥饿），过热的人还会闯进你的场景。<30 过冷：时段结束怨气 +1，满 2 触发麻烦事件。30–70 安全：主角安全且无人过热才算「完美」。
- 这个时段没见到的人注意力 −4，五个人要轮着照顾。
- 选项三类：热情（大幅 +，陷阱）/ 敷衍（小幅 −，安全）/ 甩锅（自己 −，第三人 +）。选项不显示数字，选完看脸色和条；实际结果另有 ±10 波动。
- 每拍 4.5–6 秒倒计时，超时「慌了」随机选，偏向热情型陷阱。键盘 A/B/C 选项，空格继续。
- 场景有旁观者：甩锅给在场的人效果 ×1.5 并当场反应，旁观者被你对主角的态度带动 40%。
- 老板正向 ×1.5，≥90 直接留你加班。小张受传染。小林每时段随机 ±15，过热会跟着你。老师慢热难甩。妈冷落就来电，不接两次连打五个。
- 饥饿 100 起，每时段 −6，陪聊和被缠住额外扣，归零即败。
- 评级：S 零事故且完美 ≥ 8；A 事故 ≤ 2；B 其他。
- 道具最多 3 个，倒计时里随时点：口罩（热情减半）、耳机（−10）、急事短信（−20）、充电宝（挡一次缠住）、墨镜（旁观者免疫）、关东煮（+10 饥饿）、咖啡（+5 秒）。
- 三招随时用、不消耗对话拍：装透明（溜走，成功率看对方状态，失败 +12，每场 1 次）、支走（点名任何人当借口：对方 −15、被点名 +15，每天 3 次）、装忙（本句不升温，饥饿 −3，每场 1 次）。流浪猫和柯基会在第 2 拍闯进来当旁观者。
- 路人和动物不是对话：动物是「按住摸、在刚好松手」，陌生人是「趁 TA 目光扫向别处时按走」。每句倒计时 10 / 8.5 / 7.5 秒，反应页手动翻。
- 二选一的时段有四分之三概率多出一个「路人」：流浪猫、柯基、发传单的、问路大爷、广场舞阿姨、外卖小哥、借手机的。处理得刚好掉道具，太热被硬控；代价是这一时段熟人都没见到。
