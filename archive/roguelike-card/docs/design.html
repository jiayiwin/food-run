《今天必须吃到饭》—— Roguelike 卡牌详细设计

从《下班了，我要吃饭》六方向中选定方向 ①。本页是数值与规则定稿，与仓库 docs/GDD.md 同步；可玩原型按此实现。

每次下班是一局。在「公司 → 路上 → 到家」的分叉路图上选节点，遭遇 NPC 时出牌说服对方放你走。 饥饿值是时钟（归零即败），面子值是弹药（借口消耗面子），最后一口饭才算赢。
平台 · 手机竖屏 Web，后续移植微信小游戏 单局 · 8–15 分钟 开发难度 · 中等 v0.1 原型 · 纯前端，无构建步骤

核心循环

选节点→进入节点（饥饿 −3）→遭遇：出牌回合制 / 事件：二选一 / 补给：三选一→胜利：三选一拿牌→回地图→家门 BOSS 三阶段→吃到了
一局约 15 个节点、9 次遭遇、每次 3–5 回合。选路策略是第一层决策：避开精英还是冲奖励；出牌是第二层：这回合压粘性，还是先稳住面子。

🃏 手牌与牌组

开局 10 张，每回合 3 能量、抽 5回合结束弃全部手牌；抽牌堆空时洗弃牌堆。
借口「用烂了」同名借口牌全局用过 2 次后说服减半，牌面标「用烂了」。这是局内最重要的牌组压力：逼玩家多样化借口。
五种牌借口 主输出，耗面子 · 社交 镇定 / 抽牌 / 干扰意图 · 道具 环境事件解药 · 绝招 稀有爆发 · 学科 老师专属临时牌

遭遇规则（回合制）

粘性 = NPC 的 HP归零即脱身。粘性受面子区间与精英修正。
意图公开唠叨：粘性 +N（回血）· 拖时间：饥饿 −N · 追问：面子 −max(0, N − 镇定) · 提问（老师）：回合内未打出对应学科牌，面子 −8 · 加班（老板，疑心 ≥ 5）：面子 −15、粘性 +8、疑心清零
镇定本回合累计，NPC 行动后清零。类似 Slay the Spire 的格挡，只挡「追问」。
回合流程抽牌 → 出牌（能量限制）→ 结束回合 → NPC 行动 → 饥饿 −1 → 判负检查 → 下一回合。

技术：纯前端 HTML + 原生 ES Module，无构建步骤。逻辑层（src/battle.js、src/run.js、src/map.js、src/data/）不依赖 DOM，可直接搬进小游戏；UI 层在 Canvas 重写。随机数可序列化，同种子可复盘。

结算

胜利「吃到了」：评级 S（饥饿 ≥ 40 且面子 ≥ 50）/ A（饥饿 ≥ 20）/ B。失败「饿昏倒地，梦里吃到了」：显示倒在哪一幕、被谁拖住。

验收标准（v0.1）

  1. 贪心策略 AI 200 局胜率 30%–90%；随机策略 AI 200 局不崩溃、胜率 < 30%。自动化测试
  2. 借口「用烂了」减半在同一局内跨遭遇生效。自动化测试
  3. 饥饿 < 20 时 ≥ 2 费与绝招不可打出；饥饿 0 判负。自动化测试
  4. 老板疑心 ≥ 5 触发加班；「汇报进展」能压疑心。自动化测试
  5. 接过家人电话则家门 BOSS 跳过阶段 2。自动化测试
  6. 刷新页面后可从标题页「继续上局」。存档往返测试
