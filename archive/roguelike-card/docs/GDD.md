# 《今天必须吃到饭》详细设计文档（v0.1 可玩原型）

> 项目代号 BellyFirst。方向来自《下班了，我要吃饭》六方向概念文档中的 ①「Roguelike 卡牌 + 叙事」。
> 本文是开发用的数值与规则定稿，原型代码以本文为准；改规则先改本文。

## 1. 一句话

每次下班是一局。玩家在「公司 → 路上 → 到家」的分叉路图上选节点，遭遇 NPC 时用手牌「说服」对方放你走。
**饥饿值是时钟**（归零即败），**面子值是弹药**（借口消耗面子），**最后一口饭才算赢**。

## 2. 范围（v0.1）

| 包含 | 不包含（后续版本） |
|---|---|
| 完整单局：3 幕 15 个节点、6 类 NPC、3 阶段家门 BOSS | 局外成长 / 解锁 |
| 回合制卡牌遭遇（能量、抽牌、镇定、意图） | 牌升级、商店、货币 |
| 遭遇 / 精英 / 补给 / 事件 四类节点 | 每日种子排行榜（需后端） |
| 28 张牌：借口 / 社交 / 道具 / 绝招 / 学科 | 美术资源（原型用 emoji + 扁平 UI） |
| 胜负结算、断线续局（localStorage） | 音效 / 动画 |

技术：纯前端 HTML + 原生 ES Module，无构建步骤，手机竖屏优先；后续可直接搬进微信小游戏（Canvas 重写 UI 层，逻辑层不变）。

## 3. 核心循环

```
选节点 → 进入节点（饥饿 −3） → 遭遇：出牌回合制 / 事件：二选一 / 补给：三选一
      → 遭遇胜利：三选一拿牌 → 回到地图 → … → 家门 BOSS 三阶段 → 「吃到了」
```

单局目标时长 8–15 分钟（约 15 节点，9 次遭遇，每次 3–5 回合）。

## 4. 资源系统

### 4.1 饥饿值（0–100，开局 100）

| 事件 | 变化 |
|---|---|
| 进入任意节点 | −3（基础衰减，吃零食后每次 +1） |
| 遭遇中每回合结束 | −1 |
| NPC「拖时间」意图 | −3 ~ −6 |
| 补给点「吃零食」 | +20，但基础衰减永久 +1 |
| 道具牌「零食」 | +8 |

- **< 20：判断力下降**。费用 ≥ 2 的牌和所有绝招牌不可打出（变灰）。
- **= 0：局失败**，结算动画「饿昏倒地，梦里吃到了」。

预算校验：15 节点 × 3 = 45，遭遇约 9 × 4 回合 = 36，拖时间约 25，合计 ~105，减去补给 +20 和事件回复，玩家不犯错时到家剩 15–30 点；逼着玩家在最后一幕进入「判断力下降」区间是预期体验。

### 4.2 面子值（0–100，开局 60）

| 区间 | 效果 |
|---|---|
| > 80「人缘太好」 | 遭遇开始时 NPC 粘性 ×1.2（大家都想拉着你聊） |
| 30–80 | 正常 |
| < 30「没面子」 | 遭遇开始时 NPC 粘性 ×1.25，借口牌费用 +1 |
| = 0 | 不判负，保持上面的惩罚 |

面子来源：借口牌消耗 2–10；社交牌「夸一句」「深呼吸」回复；事件选项；击败精英 +5、击败老板 +10。NPC「追问」意图扣面子，可用「镇定」抵挡。

### 4.3 手牌 / 牌组

- 开局 10 张固定牌组，每回合能量 3，抽 5 张，回合结束弃全部手牌，抽牌堆空时洗弃牌堆。
- **借口牌同一张（按牌名）全局使用 2 次后，说服效果减半**，牌面标「用烂了」。这是局内最重要的牌组压力：逼玩家多样化借口。
- 牌类型：

| 类型 | 定位 | 主要效果 |
|---|---|---|
| 借口 | 主输出，消耗面子 | 说服（扣 NPC 粘性） |
| 社交 | 防御与节奏 | 镇定（抵挡追问）、抽牌、回面子、干扰意图 |
| 道具 | 环境事件解药 | 事件里消耗以免罚；遭遇里也有小效果 |
| 绝招 | 稀有爆发 | 高说服、高面子代价，饥饿 < 20 不可用 |
| 学科 | 老师专属 | 老师发卷时临时加入，答对提问大额说服 |

## 5. 遭遇（回合制）规则

- NPC 有 **粘性**（HP）。粘性归零 = 脱身胜利。
- NPC 每回合公开一个 **意图**（StS 式），玩家出完牌点「结束回合」后结算：
  - 唠叨：粘性 +N（回血）
  - 拖时间：饥饿 −N
  - 追问：面子 −max(0, N − 镇定)
  - 提问（老师）：本回合内未打出对应学科牌 → 面子 −8
  - 加班（老板，疑心 ≥ 5 时）：面子 −15、粘性 +8，疑心清零
- **镇定**：本回合累计值，NPC 行动后清零。
- 回合流程：抽牌 → 出牌（能量限制）→ 结束回合 → NPC 行动 → 饥饿 −1 → 判负检查 → 下一回合。

| 邻居大妈 | 2 BOSS | 精英 | 30 | 唠叨+6 → 追问 5 → 「介绍对象」追问 10 | 无 |

| 室友 | 3 | 普通 | 15 | 唠叨+4 → 拖时间−3 | 无 |
| 家门 BOSS | 3 BOSS | 三阶段 | 25 / 20 / 20 | 见下 | 阶段 2 若路上接过家人电话则跳过 |

家门 BOSS 三阶段：
1. 「饭还没好」：拖时间 −5 → 唠叨 +4
2. 「先把垃圾倒了」：追问 6 → 拖时间 −4（接过电话 → 家人说「知道你饿，先吃」，跳过）
3. 「外卖迟到了」：拖时间 −6 → 唠叨 +5
三阶段全部清空 → **「吃到了」**。

## 8. 地图

- 3 幕：公司（6 层）→ 路上（6 层）→ 到家（3 层）。每层 2–3 个节点，节点连向下一层列号相差 ≤ 1 的节点。
- 第 1 层固定普通遭遇；每幕最后一层为该幕 BOSS；倒数第二层保证至少 1 个补给。
- 其余节点随机：遭遇 50%、事件 30%、补给 15%、精英 5%（第 1 幕精英 = 话多同事强化版 粘性 ×1.5）。
- 节点类型提前可见，玩家据此选路：避开精英还是冲奖励。

## 10. 补给节点（三选一）

吃零食（饥饿 +20，基础衰减永久 +1）/ 删一张牌 / 整理心情（面子 +10）。

## 11. 结算

- 胜利：「吃到了」。显示回合数、使用借口次数、剩余饥饿、剩余面子、评级（S：饥饿 ≥ 40 且面子 ≥ 50；A：饥饿 ≥ 20；B：其他）。
- 失败：「饿昏倒地，梦里吃到了」。显示倒在第几幕第几层、被谁拖住。
- 同一种子可重开复盘（标题页显示种子）。

## 12. 验收标准（v0.1）

1. 贪心策略 AI 跑 200 局胜率在 30%–90%（有难度、也可通关）；随机策略 AI 200 局不崩溃，胜率 < 30%（瞎点不该赢）。
2. 借口「用烂了」减半在同一局内跨遭遇生效。
3. 饥饿 < 20 时 ≥2 费与绝招不可打出；饥饿 0 判负。
4. 老板疑心 ≥ 5 触发加班；汇报进展能压疑心。
5. 接过家人电话则家门 BOSS 跳过阶段 2。
6. 刷新页面后可从标题页「继续上局」。
